# Auditory  
*Source: Core Rulebook p. 629*  

Auditory actions and effects rely on sound. An action with the auditory trait can be successfully performed only if the creature using the action can speak or otherwise produce the required sounds. A spell or effect with the auditory trait has its effect only if the target can hear it. This applies only to sound-based parts of the effect, as determined by the GM. This is different from a [sonic](rules/traits/sonic.md "Sonic Energy & Element Trait") effect, which still affects targets who can't hear it (such as [deaf](content/0.%20DM%20Screen/Rules/Conditions/Conditions.md#Deafened) targets) as long as the effect itself makes sound.
