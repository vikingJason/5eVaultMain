# Constrict [>](rules/core-rulebook/chapter-9-playing-the-game.md#Actions "Single Action")

- **Activate**: Single Action

The monster deals the listed amount of damage to any number of creatures [grabbed](content/0.%20DM%20Screen/Rules/Conditions/Conditions.md#Grabbed) or [restrained](content/0.%20DM%20Screen/Rules/Conditions/Conditions.md#Restrained) by it. Each of those creatures can attempt a basic Fortitude save with the listed DC.
