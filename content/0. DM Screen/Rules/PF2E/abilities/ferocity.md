# Ferocity [R](rules/core-rulebook/chapter-9-playing-the-game.md#Actions "Reaction")

- **Activate**: Reaction
- **Trigger**: The monster is reduced to 0 HP.

**Effect** The monster avoids being knocked out and remains at 1 HP, but its [wounded](content/0.%20DM%20Screen/Rules/Conditions/Conditions.md#Wounded) value increases by 1. When it is [wounded](content/0.%20DM%20Screen/Rules/Conditions/Conditions.md#Wounded), it can no longer use this ability.
